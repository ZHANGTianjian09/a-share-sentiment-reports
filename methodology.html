DATA & METHODOLOGY

数据与指标说明

这份说明解释每一条数据从哪里来、如何进入报告，以及“看多 / 看空”“恐慌 / 贪婪”“成长 / 价值”等指标应当怎样理解。

一句话概括：系统把指定财经博主视频下可公开获取的一级评论保存成时间快照，再由 DeepSeek 将评论转换为结构化标签，最后由 Python 汇总并生成报告。报告衡量的是这些评论区样本所反映的情绪，不是全体投资者情绪，也不是行情预测。

01 · PIPELINE

完整数据链路

指定博主与视频
MediaCrawler 采集
原始快照落盘
DeepSeek 结构化
Python 汇总成 PDF

采集、模型分析和报告生成是三个相互独立的阶段。原始评论不会因为模型分析或报告更新而被改写；DeepSeek 的原始响应、校验后的结构化结果和最终 PDF 也分别保存。这样可以在不重新访问抖音的情况下重新分析历史数据，或在指标口径变化后重新生成报告。

DeepSeek 做什么

理解中文评论、俚语、反讽和上下文，把文本转换成固定 JSON 字段。当前使用官方 API 的 V4 Flash 非思考模式。

Python 做什么

确定时间窗口、去重、校验字段、计算比例与平均分、绘制折线图、排序博主并生成 PDF。Python 不自行“理解”评论语义。

02 · TIME WINDOWS

盘前与收盘前是两份独立快照

盘前报告

上一交易日 14:00 → 当日 08:30
反映隔夜至盘前的新增公开评论。

收盘前报告

当日 08:30 → 当日 14:00
反映盘前之后至收盘前的新增公开评论。

两个区间首尾衔接、互不重叠。收盘前报告可以成为网站上的最新视图，但不会覆盖盘前快照。所有历史快照均保留，以便未来回测并减少前视偏差。

历史回填与实时快照不同：实时快照是在截止时刻保存当时可获取的数据；历史回填则根据后来采集到的评论时间戳重建过去区间。历史报告会明确标注“历史回填重建”，不能把它当成当时真实执行的实时采集。

03 · COLLECTION

采集了什么，没有采集什么

  • 对象：配置中指定的 12 位财经博主，以及信息窗口涉及的视频。
  • 评论层级：只保存公开可获取的一级评论，不进入任何二级回复或嵌套讨论。
  • 增量规则：新区间发布的视频获取区间内可取评论；此前已经跟踪的视频只补充尚未保存的新评论，避免重复。
  • 唯一标识：使用 comment_id 去重；同一条评论不会因为多次回访而重复进入统计。
  • 视频上下文：可用时向模型提供视频标题与平台字幕，帮助理解“他又奶了”“反向指标”等省略语；字幕只作为背景，不能被当成评论者观点。
  • 隐私：公开报告不展示评论者昵称或用户 ID。原始数据中的昵称会脱敏，用户标识只保留不可逆散列用于去重和审计。

“全量”指的是在当次快照中，程序把平台接口当时能够返回的公开一级评论持续分页取完；它不等于抖音历史上存在过的全部评论。删除、折叠、排序、登录状态和平台返回限制都可能使页面显示数与实际可取数不同。

04 · COMMENT LABELS

每条评论交给 DeepSeek 返回什么

字段允许值含义
market_relatedtrue / false评论是否确实涉及股票、基金、指数、交易、市场情绪或相关投资话题。
sentimentbullish / neutral / bearish评论者对未来方向的判断：看多、中性或看空。提问、事实陈述和方向不明通常为 neutral。
fear_greed_score-1 / 0 / 1-1 恐慌；0 没有明显情绪强度；1 贪婪。普通看跌不自动等于恐慌，普通看涨也不自动等于贪婪。
style_score-1 / 0 / 1-1 价值；0 无明确风格；1 成长。看涨不自动等于成长，看跌不自动等于价值。
stock_mentions市场实体数组评论中明确出现的公司、个股、行业或市场主题。字段名为历史兼容名称；提及不代表推荐或看多。
sarcasmtrue / false是否存在较明确的反讽、阴阳、玩笑式反话或反向表达。
reason_short简短文字供人工抽查使用的判定依据，不参与分数计算，也不在公开报告展示。

几个容易混淆的例子

评论方向恐慌 / 贪婪成长 / 价值
可能还要跌，暂时观望看空0，中性0，无倾向
彻底完了，明天全部割肉看空-1，恐慌0，无倾向
牛市来了，闭眼满仓梭哈看多1，贪婪0，无倾向
长期看好，等回调再买看多0，中性0，无倾向
AI 和半导体继续看好看多0，中性1，成长
还是低估值高股息更稳看多0，中性-1，价值

非市场评论统一返回 neutral、fear_greed_score=0、style_score=0，且不提取股票。模型输出必须通过本地严格校验：字段不能多、不能少，分数只能是 -1/0/1，评论 ID 必须与输入一一对应。校验失败的批次不会写入正式结果。

05 · CORE METRICS

三项核心指标怎样计算

三个总体指标都以 market_related=true 的有效市场评论为基础。每条评论先映射成 -1、0 或 1，再计算算术平均值，因此最终结果自然落在 -1 到 1 之间。

看多 / 看空

bullish=1，neutral=0，bearish=-1。

-1 看空0 中性1 看多

恐慌 / 贪婪

直接使用 fear_greed_score。

-1 恐慌0 中性1 贪婪

成长 / 价值

直接使用 style_score。

-1 价值0 无倾向1 成长
总体分数 = 有效市场评论分数之和 ÷ 有效市场评论数量

方向分也等价于“看多评论占比 − 看空评论占比”。例如，100 条有效市场评论中有 40 条看多、35 条中性、25 条看空，则方向分为 (40−25)÷100=+0.15。

报告中的“偏多、偏空、恐慌、贪婪、成长、价值”等文字是为了便于阅读而生成的区间标签；旁边的小数才是用于时间比较的连续结果。接近 0 表示没有明显总体倾向，并不意味着所有评论都中性，也可能意味着正负意见相互抵消。

06 · FIVE-DAY TRENDS

五日折线图为什么有十个点

每个交易日有盘前和收盘前两个独立快照，因此完整五个交易日最多包含十个点。横轴直接标注起止日期，例如“8月3日盘前”和“8月7日收盘前”。

  • 缺失快照会让折线断开，不会用 0 自动补齐。
  • 三张图分别展示看多/看空、恐慌/贪婪、成长/价值。
  • 纵轴根据各自五日真实数据动态缩放，让变化可见；图中同时标出真实上下界。
  • 动态缩放设置了最小跨度，避免极小的模型噪声被视觉上夸大成剧烈变化。

阅读时先看刻度：两条形状相似的曲线，如果纵轴范围不同，实际变化幅度可能完全不同。不能只凭折线的陡峭程度下结论。

07 · CREATORS & MENTIONS

博主评论一览与提及 Top 5

为什么只展示五位博主

当前系统覆盖 12 位博主。PDF 按本期有效市场评论数从高到低展示前五位，剩余博主合并为“其他博主（7位）”，从而在一页内保持可读性。

“其他博主”的分数不是简单平均七位博主的平均值，而是把这些博主的底层有效评论合并后重新计算。这样不同样本量不会被错误地赋予相同权重。表格中的“较前次”用于描述与可比较快照之间最明显的变化。

提及 Top 5

DeepSeek 从每条评论中提取明确出现的股票名称、简称或代码；同一条评论内的重复名称只计一次，再按所有评论的命中次数排序。它反映“讨论次数”，不表示看多、推荐、买入量或资金流向。

08 · HOW TO READ

一页报告建议这样读

① 标题与数据窗口

先确认盘前还是收盘前、截止时间和是否属于历史回填。不同窗口不能混为同一时点。

② 市场情绪速览

DeepSeek 只接收 Python 已计算的聚合指标，从中选择最突出的一个状态，用 10–25 个中文字概括。它不得虚构原因、新闻、预测或投资建议。

③ 样本概况

检查博主数、视频数、一级评论数、市场相关率和分析成功率。样本明显变少时，指标稳定性也会下降。

④ 三项指标

同时看文字方向、具体分数和过去五日折线。单个时点回答“现在是什么状态”，折线回答“状态正在怎样变化”。

⑤ 博主评论一览

判断总体结果是否由少数高评论量博主推动，以及不同博主之间是否存在明显分歧。

⑥ 高频提及

可能包含公司、个股、行业或主题，用于观察讨论焦点，不应理解成选股清单。

市场情绪速览的生成边界

一句话综合评价不读取新闻，也不重新阅读全部原始评论。它接收当前指标、五日变化、样本量和关注度信息，只选择最值得注意的一项。例如：恐慌快速升温，处于近五日高位多空分歧明显，整体情绪中性市场话题聚焦度较低

“市场相关率低”只能说明评论区对市场话题的聚焦度较低；只有有效市场评论数量也显著低于过去五个同类型快照时，才可以描述为“市场讨论关注度较低”。盘前只和过去盘前比较，收盘前只和过去收盘前比较。

09 · QUALITY & LIMITS

数据质量、偏差与使用边界

平台可获取性

评论接口可能因登录、验证码、平台限制、删除或折叠而返回不完整数据。程序不会绕过访问控制，遇到限制会暂停并保留断点。

博主受众偏差

评论区用户不是随机抽样的全体投资者，不同博主的受众结构和视频主题会显著影响情绪分布。

模型分类误差

中文俚语、反讽、上下文缺失和股票简称可能导致误判。系统保留 reason_short 和原始响应，用于人工抽查与重新分析。

评论量不等于人数

一个人可以发表多条评论。报告按评论计权，不代表独立投资者人数，也不代表资金规模。

报告是研究型情绪观察工具，不构成证券评级、收益预测或投资建议。任何分数都应与样本量、数据窗口、博主分布和历史趋势一起阅读，不应作为单独的交易信号。

当前方法版本：v1.0。若未来字段、阈值或时间边界发生变化，报告与本页面应同步记录版本，避免把不同口径的结果直接比较。

本说明对应“每日市场情绪报告”的当前原型口径。
